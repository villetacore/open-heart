# «Свет для общего стола» — игровая партия 27.09.2026

В основную кампанию добавлены **4 задания, 21 сцена RU/EN и 47 новых реплик**. Это продолжение историй соседей с головоломкой, исследованием и разговорами. В пресете теперь 41 задание и 154 сцены диалогов.

## Как начать и пройти

Поговори с **Эш**, электриком на южной дороге: координаты X/Z **(7, 34)**. Выбери «Чем могу помочь?». Новая история открывается после её задания «Образцы для фонарей» (`neighbors_ash_2`). Незавершённые прежние задания соседей сохраняются.

| Задание | Кто выдаёт | Цель после принятия | Условия |
|---|---|---|---|
| Свет без мерцания | Эш | Синхронизировать одну группу реле; головоломки появляются с глубины 2 | `neighbors_ash_2` |
| Не только имена победителей | Ноэль | Прослушать одно эхо памяти; сюжетные комнаты появляются с глубины 3 | Предыдущий этап и `neighbors_noel_2` |
| Тише, чем обычно | Люсьен | Поговорить с Ивом о тихом месте | Предыдущий этап и `neighbors_lucien_2` |
| Место за столом | Эмиль | Пригласить Рена и вернуться | Предыдущий этап и `neighbors_emil_2` |

Старые решения реле, прослушанные записи и встречи до принятия не засчитываются. У Ива и Рена есть отдельные ответы о вечере; счётчик взаимодействия, как и в других заданиях игры, срабатывает при начале разговора. Принятые цели показываются существующими журналом и навигацией.

Награды по этапам: 180/180/90/160 XP, 70/70/35/60 золота, аптечка за каждый из первых трёх этапов, два хлеба за финал. Всего **610 XP, 235 золота, 3 аптечки и 2 хлеба**. Изъятия квестовых предметов нет; сбор не используется. Предварительные задания дают собственные награды отдельно.

## Что меняется после завершения

- Рядом с Эмилем, в **(-11, 0, 43)**, появляется общий стол: столешница, опоры, две лавки, три светящихся свечи и локальный свет. Это декоративная геометрия без новой механики сидения и без коллизии.
- Завершение квеста и флаг `shared_evening` сохраняются штатным форматом сейва; новый формат сохранений не нужен.
- Показывается отдельная иллюстрация вечера с шестью жителями и шестью репликами. Это сюжетный рисунок; персонажи не телепортируются к столу в 3D-мире.
- У всех шести соседей открывается тема «Как тебе общий вечер?» — по две новые реплики. Отсюда можно вновь посмотреть финальную сцену, без повторной награды.

## Изменения движка для контента

1. Поле реплики `portrait` теперь принимает явный путь `res://assets/...png` или `.tres`, например `res://assets/illustrations/neighbors/shared_evening_v1.png`. У автора есть выбор иллюстрации на уровне реплики без правки Rust и без специального суффикса названия сцены. Старые ключи NPC и `_city` продолжают работать.
2. Перед каждой репликой старая текстура очищается. Неизвестный ключ или неудачная загрузка больше не оставляет чужое изображение.
3. Иллюстрации получили область 700×390 вместо 700×290. Текст прокручивается в своей области и не перекрывает рисунок. Прокрутка сбрасывается при переходе к следующей реплике.
4. Выбор ответа проверяет условия принятия и готовность задания даже при прямой ссылке на авторскую сцену. Нельзя обойти зависимости через `next` или сдать неподготовленный квест.
5. Повторная транзакция с уже завершённым `QuestDone` целиком отклоняется ядром, включая XP, золото, предметы и флаги. Для завершённого задания генератор диалога возвращает благодарность, а не сцену награды.
6. Новый `world_change.pattern = "table"` создаёт декоративный стол без вращающихся копий NPC. Существующая проверка узла по ID предотвращает дублирование.
7. Добавлен инструмент синхронизации JSON → RON с проверкой обратного преобразования. Runtime предпочитает RON, поэтому редактировать только JSON недостаточно.

## Производство следующей партии

Авторский источник эпизода — `tools/add_evening_content.py`. Скрипт повторяемый: обновляет только `evening_*` и принадлежащие эпизоду переходы, сохраняет другие записи. После запуска:

```powershell
cargo run -p openheart-core --example sync_preset -- game/presets/core quests dialogues
```

После любых изменений пресета пересчитать Go-хеш через `server/cmd/oh-content-hash` и обновить ожидаемое значение в `core/src/data/hash_disk_tests.rs`. Не менять эту константу произвольным значением ради зелёного теста.

## Проверки

- 108 тестов ядра и 29 тестов клиента: успешно. Проверены связи пресета, JSON/RON, явные пути графики, сохранение финального состояния и блокировка повторной награды.
- Go-реализация вычислила тот же хеш пресета, что Rust. `go test ./internal/content` собирает пакет; собственных тестов в этом пакете нет.
- `game/tools/evening_smoke.gd` прогоняет цепочку в Godot с изолированным `APPDATA`, не записывая личную кампанию. Проверяет ранние/повторные награды, цели, сохранение перед сдачей, общий стол, смену картинки и очистку старой текстуры.
- Реальный экран диалога снят в `target/evening-review.png`. Автоматический тест подаёт события решения реле и чтения памяти напрямую; он не заменяет ручное прохождение всего маршрута от новой игры.
- Полный релизный экспорт этой партией не выполняется. При запуске в изолированной среде Godot сообщает об отсутствии доступа к системному хранилищу сертификатов; локальные контентные проверки от этого не падают.
